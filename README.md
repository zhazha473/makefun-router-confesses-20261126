# The Router Confesses

Entry for the make.fun bounty [u-carbon-forge-the-router-confesses-f98f6b9e](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) ("The Router Confesses"): one line, at most 200 characters, in which a home Wi-Fi router excuses itself for dying at the climax of a movie.

`main.py` writes that one line to `/output/entry.txt`. It is deterministic and needs no network.

## The line

> I filed for leave three times, in writing, and HR never replied, so I approved it myself — right in the middle of the hero's big confession. You're welcome.
